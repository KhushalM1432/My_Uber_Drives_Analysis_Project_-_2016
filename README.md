# My_Uber_Drives_Analysis_Project_-_2016
# Data_Science
### 🚗Project Highlights
1. Conducted **data cleaning and preprocessing** on the Uber Drives dataset using Python libraries such as **Pandas, NumPy, and Seaborn**.
2. Removed duplicate and missing values using custom-defined functions and imputation techniques (mean/mode filling).
3. Performed **Exploratory Data Analysis (EDA)** to identify trends in ride frequency, trip categories, and customer travel patterns.
4. Saved the cleaned dataset for further analysis and visualization to gain business insights about **travel behavior and ride efficiency**.
5. Utilized **Matplotlib and Seaborn** for creating visual reports to support data-driven decision-making.
